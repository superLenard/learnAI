# 2.7 主流模型与开源生态

| 模型系列 | 出品方 | 特点 |
| --- | --- | --- |
| GPT 系列 | OpenAI | 闭源标杆，ChatGPT 的基础 |
| LLaMA | Meta | 开源权重代表，带动本地部署生态 |
| Qwen（通义千问） | 阿里 | 中文能力强，开源系列丰富（0.5B–几十 B） |
| DeepSeek | 深度求索 | 开源、性价比高，擅长推理 |
| GLM | 智谱 | 中文大模型代表之一 |

- 国内常用开源模型以 **Qwen、DeepSeek** 为主，中文效果好、生态完善。
- 用前**务必注意许可证差异**：有的完全开源可商用，有的仅学术用途，有的对商用有限制。
