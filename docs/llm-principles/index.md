## 一句话导读

大模型的本质是 **预测下一个词**，它是 **Transformer（注意力机制）+ 海量数据预训练 + 规模化** 的产物；文本先分词、再嵌入，经过多层 Transformer 提炼信息，最终输出"下一个词"的概率分布。实际使用中多基于 Qwen、DeepSeek、LLaMA 等开源模型。
