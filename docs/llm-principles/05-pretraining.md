# 2.5 预训练与规模效应

有了结构，还得"喂"数据把它训练出来。**预训练**就是在海量文本（网页、书籍、代码等）上反复做"预测下一个词"：

- **训练目标**：让模型对每个位置预测正确的下一个 token，用交叉熵损失优化参数。
- **规模效应（Scaling Law）**：数据量、参数量、算力增大，模型能力持续提升——这就是"大"语言模型"大"的原因。
- **参数量**：小模型 0.5B–7B，中大模型几十到上百 B，前沿模型甚至万亿级。
- **预训练 vs 指令微调**：预训练让模型"会生成"，指令微调/对齐让它"会按要求回答"（对应路线阶段四）。

预训练极其烧钱（动辄数千万到数亿美元算力），所以开源社区多是**预训练好的开源模型**（如 Qwen、LLaMA、DeepSeek），我们直接拿来做推理或微调，不必自己从零训练。
