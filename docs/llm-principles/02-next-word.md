# 核心思想：预测下一个词

大语言模型（LLM）的底层逻辑虽然由成百上千亿的参数构成，但其核心行为可以简化为一个优雅的日常游戏：**文字接龙**，学术上称为 **“预测下一个词”（Next-Token Prediction）**。

本篇将通过李白的名句 **“两岸猿声啼不住，轻舟已过万重山”**，为您具象化演示大模型是如何在数十万词表里进行概率筛选的，并深度剖析 **Temperature（采样温度）** 参数如何像控制阀一样改变模型的创造力。

## 2.2.1 “下一个词预测” 动态生成演示

当大模型接收到上文时，它的任务是预测最合理的下一个词。模型不会一次性生成整句话，而是**一个Token（词/字）接一个Token地循环预测**。

以下是句子 **“两岸猿声啼不住，轻舟已过万重山”** 逐步生成的概率漏斗：

| 预测步骤 (Step) | 模型接收到的上文 (Context) | 候选词概率分布 (Candidates & Probability) | 模型最终选择 (Output) |
| :--- | :--- | :--- | :--- |
| **Step 1** | 两岸猿声啼不住， | **轻舟 (85%)** / 孤帆 (10%) / 白帝 (3%) / 飞鸟 (2%) | **轻舟** |
| **Step 2** | 两岸猿声啼不住，轻舟 | **已过 (92%)** / 难过 (4%) / 穿过 (3%) / 荡过 (1%) | **已过** |
| **Step 3** | 两岸猿声啼不住，轻舟已过 | **万重 (78%)** / 千重 (15%) / 几重 (5%) / 崇山 (2%) | **万重** |
| **Step 4** | 两岸猿声啼不住，轻舟已过万重 | **山 (99%)** / 峦 (0.6%) / 岭 (0.3%) / 嶂 (0.1%) | **山**（生成结束） |

## 2.2.3 深度剖析：Temperature（采样温度）控制阀

在上一节的 SVG 图中，我们可以看到一个**温度阀**。在现实中，如果大模型永远只选择概率最高（85%）的词，那么它写出来的文章将会千篇一律、极其死板。

**Temperature（温度参数，通常范围在 0.0 到 2.0 之间）** 就是大模型用来平衡**稳定性**与**创造力**的秘密武器。它从底层改变了候选词的概率分布：

### 2.2.3.1 低温度（Temperature = 0.0 - 0.3） —— 严谨的复刻者
* **机制**：强者更强，弱者更弱。高概率词的统治力被无限放大，其余低概率词直接被压缩到趋近于 0。
* **生成效果**：模型进入“贪婪搜索（Greedy Search）”状态。
* **经典表现**：
  > 接收：“两岸猿声啼不住，” $\rightarrow$ **必定输出**：“轻舟已过万重山。”
* **适用场景**：代码编写、数学计算、公文写作、客观事实问答。

### 2.2.3.2 中温度（Temperature = 0.7 - 1.0） —— 优雅的诗人
* **机制**：保持统计学上的常态分布。原本概率最高的词依旧最可能被选中，但次高概率的词也获得了登场的门票。
* **生成效果**：模型在理智与灵感之间达到了最佳平衡。
* **创造性表现**：
  > 接收：“两岸猿声啼不住，” $\rightarrow$ **可能输出**：“**孤帆**已过万重山。”（通过 10% 的概率，模型选择用更具孤独感的“孤帆”替代了原本的“轻舟”，产生文学质感）。
* **适用场景**：小说创作、文案润色、头脑风暴、日常对话。

### 2.2.3.3 高温度（Temperature = 1.5 - 2.0） —— 混乱的胡话者
* **机制**：概率被“烫平”。原本 85% 概率和 3% 概率的词在得分上变得所差无几，选择变得近乎完全随机。
* **生成效果**：模型完全丧失逻辑，陷入随机熵增。
* **崩塌表现**：
  > 接收：“两岸猿声啼不住，” $\rightarrow$ **混乱输出**：“**白帝**已过万**岭**。”（句意逻辑崩塌）。
* **适用场景**：极度前卫的先锋艺术创作或密码生成。

## 2.2.4 总结：从字词接龙到涌现智能

无论是背诵一首古诗，还是解答复杂的量子力学问题，大模型的本质都是在通过上文计算下一个词的条件概率分布：

$$P(Token_{t} | Token_{1}, Token_{2}, \dots, Token_{t-1})$$

大模型通过 **Temperature 采样温度** 调节概率分配，而近年出现的 **推理模型（如 DeepSeek-R1、OpenAI o1）**，则是通过在最终输出“轻舟”之前，在内部生成成千上万个“看不见的 Token” 进行自我反思、纠错和逻辑推演（即长思维链 CoT），从而让简单的“预测下一个词”真正质变为高等的智能推理。
