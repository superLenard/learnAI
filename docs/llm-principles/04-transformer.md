# 2.4 Transformer 机制：大语言模型的核心架构

## 2.4.1 Transformer 是什么？

Transformer 是一种以注意力机制（Attention）为核心的神经网络架构。它由 Google 研究团队在 2017 年发表的论文《Attention Is All You Need》中提出。

在 Transformer 出现之前，自然语言处理任务广泛使用循环神经网络（RNN）及其变体，例如 LSTM。RNN 按照序列顺序处理输入，当前步骤的计算依赖前一步的隐藏状态。这种结构在处理长序列时不容易充分利用并行计算资源，也可能面临长距离依赖学习困难的问题。

Transformer 改变了信息处理方式：它通过注意力机制，直接计算序列中不同位置之间的关联，让每个位置能够根据任务需要，从其他位置聚合信息。

例如：

> 小明把苹果放进冰箱，因为它很热。

理解“它”时，模型需要结合上下文判断代词与其他词语之间的关系。Self-Attention 会为当前位置计算对其他位置的注意力权重，再根据这些权重融合上下文信息。

需要注意，Attention 权重表达的是模型在当前计算中的信息聚合关系，不应简单等同于人类语言中的因果关系或完整解释。

### Transformer 的主要特点

1. **便于并行训练**：训练时，序列中多个位置的计算可以通过矩阵运算并行完成。
2. **能够建模长距离关系**：任意两个位置都可以在注意力计算中建立直接联系。
3. **易于扩展**：可以通过增加层数、隐藏维度、注意力头和训练数据规模来构建更大模型。
4. **适用范围广**：除文本外，Transformer 及其变体也用于图像、语音和多模态任务。

## 2.4.2 Transformer 的三种典型架构

原始 Transformer 采用 Encoder-Decoder（编码器—解码器）结构。后来，研究者根据不同任务，发展出三种常见架构。

### 2.4.2.1 Encoder-only：仅编码器

Encoder 的主要任务是理解输入序列，并生成包含上下文信息的表示。

典型特点：

- 通常允许一个位置关注输入序列中的前后文。
- 适合文本分类、语义表示、信息抽取等理解类任务。
- 典型代表：BERT。

### 2.4.2.2 Decoder-only：仅解码器

Decoder-only 模型主要用于根据已有上下文预测后续 Token。

典型特点：

- 使用因果注意力掩码，避免当前位置访问未来 Token。
- 通常采用自回归方式生成文本。
- 典型代表：GPT、LLaMA 等生成式语言模型。

Claude 等现代生成式语言模型也属于以 Decoder-only Transformer 为基础的模型路线，但具体架构细节可能并不公开或完全相同。

### 2.4.2.3 Encoder-Decoder：编码器与解码器

Encoder 先理解输入序列，Decoder 再结合编码器输出生成目标序列。

典型应用包括机器翻译、摘要和文本转换。代表模型包括原始 Transformer 和 T5。

| 架构 | 组成 | 常见用途 | 代表模型 |
|---|---|---|---|
| Encoder-only | Encoder | 文本理解、分类 | BERT |
| Decoder-only | Decoder | 文本生成、对话、代码生成 | GPT、LLaMA |
| Encoder-Decoder | Encoder + Decoder | 翻译、摘要、文本转换 | T5 |

本节后续重点介绍现代生成式大语言模型常见的 Decoder-only 结构。

## 2.4.3 从 Token ID 到 Transformer 输入

结合 2.3 的 Tokenizer 内容，可以把模型处理文本的过程分成以下几个步骤。

### 第一步：文本切分与 Token ID 映射

假设输入文本为：

```text
我喜欢人工智能
```

Tokenizer 会根据模型自己的词表和切分规则，将文本转换为 Token 序列，再映射为整数 ID。

以下仅为示意，实际 Token 切分和 ID 由具体模型决定：

| Token | 示例 Token ID |
|---|---:|
| 我 | 1234 |
| 喜欢 | 5678 |
| 人工 | 9012 |
| 智能 | 3456 |

Token ID 本身只是词表索引，不直接携带可供神经网络计算的语义信息。

### 第二步：Token Embedding

模型通过 Embedding 矩阵，将每个 Token ID 映射为一个稠密向量。

如果词表大小为 $V$，隐藏维度为 $d$，Embedding 矩阵可以表示为：

$$
E \in \mathbb{R}^{V \times d}
$$

对于 Token ID 为 $i$ 的输入，其向量表示就是矩阵中的第 $i$ 行：

$$
x_i = E[i]
$$

例如，一个 Token 可以被映射为：

$$
x_i=[0.12,\ 0.35,\ -0.21,\ 0.48,\ldots]
$$

实际模型的向量维度可能很大，以上数值仅用于说明。

### 第三步：注入位置信息

Attention 本身并不天然知道 Token 的顺序。模型需要通过位置编码或其他位置机制，使网络能够利用序列位置信息。

常见方式包括：

- **绝对位置编码**：为不同位置提供位置向量，原始 Transformer 使用正弦和余弦位置编码。
- **RoPE（旋转位置编码）**：通过旋转变换将位置信息融入 Query 和 Key，广泛用于现代 Decoder-only 模型。
- **其他相对位置机制**：通过相对位置关系影响注意力计算。

因此，不能简单认为所有现代 Transformer 都是把一个位置向量直接加到 Embedding 上；不同模型的位置处理方式可能不同。

### 第四步：进入 Transformer Blocks

向量进入多层 Transformer Block。每一层都会进行上下文信息交互和特征变换。

### 第五步：输出预测分数

最后一层隐藏状态经过归一化和线性投影，得到词表中每个 Token 对应的 Logit（未归一化分数）。

经过 Softmax 后，可以得到下一个 Token 的概率分布。

## 2.4.4 自注意力机制（Self-Attention）

Self-Attention 是 Transformer 的核心机制。它要解决的问题是：

**处理某个 Token 时，应该从序列中的哪些位置获取信息，以及获取多少信息？**

例如：

```text
小明告诉小红，他明天要去北京。
```

模型需要结合上下文处理“他”与句子中其他词语的关联。Self-Attention 会计算当前位置与其他位置之间的匹配分数，并据此融合信息。

### 2.4.4.1 Q、K、V 分别是什么？

Self-Attention 使用三个向量：

| 名称 | 英文 | 常见中文译法 | 直观理解 |
|---|---|---|---|
| Q | Query | 查询 | 当前 Token 正在寻找什么信息 |
| K | Key | 键 | 当前 Token 提供什么匹配特征 |
| V | Value | 值 | 当前 Token 实际提供的内容表示 |

可以用信息检索来类比：

- Query：检索请求。
- Key：用于匹配请求的索引特征。
- Value：匹配后真正取回的信息。

这只是帮助理解的类比。Q、K、V 都是模型通过训练学习得到的向量，并不是人工指定的标签。

### 2.4.4.2 Q、K、V 如何生成？

假设输入隐藏状态矩阵为：

$$
X \in \mathbb{R}^{n \times d_{\text{model}}}
$$

其中：

- $n$：序列长度，即 Token 数量。
- $d_{\text{model}}$：模型隐藏维度。

通过三个可训练的线性投影矩阵生成 Q、K、V：

$$
Q = XW_Q
$$

$$
K = XW_K
$$

$$
V = XW_V
$$

其中 $W_Q$、$W_K$、$W_V$ 是模型训练过程中学习到的参数矩阵。

### 2.4.4.3 Scaled Dot-Product Attention

首先计算 Query 与 Key 的点积，得到位置之间的匹配分数：

$$
S=QK^T
$$

然后除以缩放因子 $\sqrt{d_k}$，再经过 Softmax，得到注意力权重：

$$
A=Softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)
$$

最后使用注意力权重对 Value 加权求和：

$$
Attention(Q,K,V)=
Softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

各部分的作用：

- $QK^T$：计算 Query 与各个 Key 的匹配分数。
- $\sqrt{d_k}$：缩放因子，帮助控制点积数值的尺度。
- Softmax：将分数转换为归一化权重。
- $V$：根据权重聚合各位置的信息。

为什么需要缩放？

当 Key 维度较大时，点积的数值可能随维度增大而变大，导致 Softmax 分布过于尖锐，影响梯度传播。除以 $\sqrt{d_k}$ 可以缓解这一问题。

![Self-Attention 的 Q、K、V 计算流程](/self-attention-qkv.svg){.svg-diagram}

### 2.4.4.4 一个直观示例

假设当前处理“喜欢”这个 Token，经过注意力计算后，对三个 Token 的权重为：

| Token | 注意力权重 |
|---|---:|
| 我 | 0.25 |
| 喜欢 | 0.50 |
| AI | 0.25 |

那么当前位置的 Attention 输出，就是三个 Value 向量按照上述权重加权求和的结果。

这些数字仅用于说明计算过程。真实权重由模型参数、输入内容、位置机制以及掩码共同决定。


## 2.4.5 多头注意力（Multi-Head Attention）

一个注意力头通过一组 Q、K、V 投影计算注意力表示。为了让模型能够在不同表示子空间中学习信息关系，Transformer 使用多个注意力头。

### 2.4.5.1 多头注意力的基本思想

可以把多个注意力头理解为多个并行的信息处理通道。

例如，模型可能在不同头中学习到与语法、指代、位置或语义相关的模式。但需要注意，这些并不是人为固定分配的职责，注意力头的实际功能通常会重叠，也不一定能被简单解释。

### 2.4.5.2 多头注意力的计算过程

第 $i$ 个注意力头分别计算：

$$
head_i=Attention(Q_i,K_i,V_i)
$$

将多个头的结果拼接：

$$
H=Concat(head_1,head_2,\ldots,head_h)
$$

再经过输出投影：

$$
MultiHead(Q,K,V)=HW_O
$$

其中：

- $h$：注意力头数量。
- $W_O$：输出投影矩阵。
- 每个头具有各自的投影参数。

### 2.4.5.3 为什么需要多个头？

多头注意力可以让模型同时从多个表示子空间提取信息，而不是依赖单一的注意力表示。多个头的输出经过拼接和投影后，形成更丰富的上下文表示。

## 2.4.6 因果掩码（Causal Mask）

Causal Mask 是理解 GPT 等自回归语言模型的重要概念。

生成式语言模型通常按照从左到右的顺序预测下一个 Token。为了保证训练过程符合生成时的信息约束，当前位置不能访问未来位置的信息。

例如序列：

```text
我 / 喜欢 / 人工 / 智能
```

各位置允许关注的范围如下：

| 当前 Token | 我 | 喜欢 | 人工 | 智能 |
|---|---:|---:|---:|---:|
| 我 | 1 | 0 | 0 | 0 |
| 喜欢 | 1 | 1 | 0 | 0 |
| 人工 | 1 | 1 | 1 | 0 |
| 智能 | 1 | 1 | 1 | 1 |

- `1`：允许关注。
- `0`：屏蔽该位置。

这种矩阵是下三角形式。实际计算中，被屏蔽位置会在 Softmax 之前加入负无穷或数值上等效的极小值，使其 Softmax 权重为 0。

### 为什么 GPT 需要 Causal Mask？

GPT 的训练目标是根据前面的 Token 预测下一个 Token。如果模型在训练时能够看到目标位置之后的内容，就会发生未来信息泄漏。

Causal Mask 保证模型在预测某个位置时，只能利用当前位置之前以及当前位置允许使用的信息。

## 2.4.7 前馈神经网络（Feed Forward Network，FFN）

Attention 负责在不同 Token 位置之间聚合信息。完成信息交互后，模型还需要进一步变换每个位置的特征，这就是 FFN 的主要作用。

### 2.4.7.1 经典 FFN 结构

原始 Transformer 中的前馈网络可以表示为：

$$
FFN(x)=W_2\cdot ReLU(W_1x+b_1)+b_2
$$

它包含两个线性变换和一个非线性激活函数。

通常先把隐藏维度投影到更高维空间，再通过激活函数，最后投影回模型隐藏维度。

现代大语言模型也常使用 GELU、SwiGLU 等激活或门控结构，具体实现取决于模型设计。

### 2.4.7.2 FFN 与 Attention 的区别

| 组件 | 主要职责 | 直观理解 |
|---|---|---|
| Attention | 在 Token 位置之间交换、聚合信息 | 从上下文中获取相关信息 |
| FFN | 对每个位置的特征进行非线性变换 | 对当前特征进一步加工 |

可以简单记忆：Attention 主要解决“信息从哪里来”，FFN 主要解决“如何变换已经获得的特征”。

## 2.4.8 残差连接与归一化

随着 Transformer 层数增加，模型训练需要稳定的信息和梯度传递机制。残差连接与归一化是其中的重要组成部分。

### 2.4.8.1 残差连接（Residual Connection）

残差连接将子层输入与子层计算结果相加：

$$
y=F(x)+x
$$

其中：

- $x$：子层原始输入。
- $F(x)$：子层变换后的结果。
- $y$：残差相加后的输出。

它为信息和梯度提供了更直接的传播路径，有助于训练深层网络。

### 2.4.8.2 Layer Normalization

Layer Normalization（LayerNorm）对单个样本的特征维度进行归一化，帮助稳定网络中的激活数值分布。

现代模型中也常使用 RMSNorm。它与 LayerNorm 的计算方式不同，但同样用于改善网络训练和数值稳定性。

### 2.4.8.3 Pre-Norm 与 Post-Norm

归一化层在 Transformer Block 中的位置可以不同：

- **Post-Norm**：先经过子层计算并做残差相加，再进行归一化。原始 Transformer 使用这种排列。
- **Pre-Norm**：先归一化，再进入 Attention 或 FFN 子层，随后做残差相加。许多现代大语言模型采用类似结构。

因此，不同模型的 Transformer Block 并不一定完全相同。

## 2.4.9 GPT 类模型的 Decoder-only 结构

将前面介绍的组件组合起来，就可以理解 GPT 类模型的整体结构。

一个典型的 Decoder-only 模型通常包含：

1. Token Embedding。
2. 位置相关信息机制，例如 RoPE。
3. 多层 Decoder Transformer Block。
4. 最终归一化层。
5. 线性输出投影层。

每个 Transformer Block 通常包含：

- 因果自注意力（Causal Self-Attention）。
- 残差连接。
- 归一化层。
- 前馈网络（FFN）。
- 另一条残差连接。

具体模型可能在归一化方式、位置编码、注意力实现、FFN 结构等方面有所差异。

GPT 的自回归生成过程

假设用户输入：

```text
人工智能正在改变
```

模型大致按照以下过程工作：

```text
输入文本
   ↓
Tokenizer
   ↓
Token ID 序列
   ↓
Token Embedding
   ↓
位置相关信息
   ↓
Transformer Block 1
   ↓
Transformer Block 2
   ↓
       ...
   ↓
Transformer Block N
   ↓
Final Norm
   ↓
Linear
   ↓
Logits
   ↓
Softmax / 生成策略
   ↓
选择下一个 Token
   ↓
将 Token 加入上下文
   ↓
继续预测
```

这里需要区分 Logits、概率和最终生成结果：

- **Logits**：模型输出层产生的未归一化分数。
- **概率分布**：通过 Softmax 等处理得到的 Token 概率。
- **生成策略**：结合 Temperature、Top-k、Top-p 等设置选择下一个 Token。
- **自回归生成**：将新 Token 加入上下文，继续下一轮预测。

实际推理通常会使用 KV Cache 缓存之前位置的 Key 和 Value，避免每生成一个 Token 都重新计算全部历史位置的 K、V。这部分将在后续缓存与推理性能章节进一步展开。

## 2.4.10 Transformer 为什么能够支撑大语言模型？

### 1. 适合并行训练

训练时可以对序列中多个位置进行并行计算，充分利用 GPU 的矩阵运算能力。

需要注意：自回归模型的训练可以并行处理多个位置，但实际生成通常仍然需要逐步预测 Token。

### 2. 能够建模上下文关系

Self-Attention 允许不同位置直接建立信息联系，使模型能够学习长距离依赖关系。

### 3. 结构具有扩展性

Transformer 可以通过增加模型层数、隐藏维度、注意力头数量和参数规模，构建不同容量的模型。

### 4. 可以迁移到多种任务

Transformer 及其变体已经广泛应用于文本、代码、图像、语音和多模态任务。

## 2.4.11 Transformer 的局限性与性能优化方向

Transformer 并不是没有成本。标准全注意力机制在长上下文场景下，计算和显存开销会显著增加。

### 2.4.11.1 标准 Self-Attention 的复杂度

假设输入序列长度为 $n$，每个 Token 都需要与其他 Token 计算注意力关系，那么注意力分数矩阵的形状为：

$$
n\times n
$$

因此，标准全注意力的注意力分数计算量和矩阵规模会随序列长度呈平方级增长。

| Token 数量 | 注意力矩阵元素数量 |
|---:|---:|
| 1,000 | 1,000,000 |
| 2,000 | 4,000,000 |
| 4,000 | 16,000,000 |
| 8,000 | 64,000,000 |
| 16,000 | 256,000,000 |

以上是单个注意力头对应的矩阵元素数量示意，不包含批次、头数和数据类型等因素。

### 2.4.11.2 常见优化方向

| 技术 | 主要解决的问题 |
|---|---|
| FlashAttention | 优化注意力计算的数据访问与显存使用 |
| KV Cache | 避免自回归生成时重复计算历史 Key 和 Value |
| PagedAttention | 更高效地管理推理阶段的 KV Cache 显存 |
| GQA / MQA | 减少 Key、Value 头数量，降低缓存开销 |
| Sliding Window Attention | 限制部分注意力计算的上下文范围 |
| 量化 | 降低模型权重或缓存的存储与计算成本 |

这些技术将在后续推理、缓存与性能相关章节进一步学习。

## 2.4.12 本节总结

Transformer 是现代生成式大语言模型的重要基础架构。它通过 Self-Attention 建立 Token 之间的信息联系，再结合 FFN、残差连接和归一化等组件，逐层处理上下文特征。

本节需要掌握的核心概念：

| 概念 | 核心作用 |
|---|---|
| Transformer | 基于注意力机制的网络架构 |
| Encoder | 对输入序列进行上下文编码 |
| Decoder | 根据已有上下文生成后续内容 |
| Embedding | 将 Token ID 转换为向量 |
| 位置机制 | 让模型利用 Token 的位置信息 |
| Self-Attention | 计算并聚合不同位置的信息 |
| Q / K / V | 查询、匹配特征和信息表示 |
| Multi-Head Attention | 在多个表示子空间中并行计算注意力 |
| Causal Mask | 屏蔽未来位置，保证自回归预测的信息约束 |
| FFN | 对隐藏特征进行非线性变换 |
| Residual | 保留输入信息，改善梯度传播 |
| LayerNorm / RMSNorm | 改善数值分布与训练稳定性 |

**一句话总结：**

Transformer 通过注意力机制让 Token 之间相互获取信息，再通过前馈网络逐层加工特征，最终使大语言模型能够根据上下文预测和生成下一个 Token。
