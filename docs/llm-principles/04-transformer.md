# 2.4 Transformer 机制

现代大模型几乎都基于 **Transformer**（2017 年论文《Attention Is All You Need》提出）。它彻底取代了 RNN/LSTM，核心武器是**注意力机制（Attention）**。

下面是生成式模型（解码器）的架构图，自上而下看它的处理流程：

![Transformer 架构（生成式解码器）](/transformer-arch.svg)

解码器里各组件的作用：

| 组件 | 作用 |
| --- | --- |
| **掩码多头自注意力** | 每个 token 只看"前面"的 token，用多组注意力捕捉不同角度关系 |
| **残差连接 + 层归一化** | 稳定训练、防止梯度消失，让几十上百层能堆起来 |
| **前馈网络（FFN）** | 对每个位置的表示做非线性变换，增强表达能力 |
| **线性层 + Softmax** | 把输出映射成词表上的概率分布，选下一个词 |
| **位置编码** | 给 token 带上位置信息，因为注意力本身不分先后 |

一句话理解注意力：

> 生成当前词时，模型计算它与前面每个 token 的"相关度"，按相关度加权融合信息——这就是"注意到"哪些词更重要。

多头注意力让模型能同时关注多种关系（语法、指代、主题等），是它能处理复杂句子的关键。整体结构会**重复堆叠 N 层**，层数越多，表达越强，也越"大"。
