# 第一章 AI 学习路线

> 本文按"基础 → 原理 → 训练/微调 → 推理/部署 → 工程落地 → 持续进阶"的顺序，梳理一条**以大模型为核心的 AI 系统学习路线**。它既是本博客的目录骨架，后续章节会逐块展开具体笔记。建议以"学一段、练一段、记一段"的节奏推进，先动手再深挖原理。

## 1.1 路线全景

| 阶段 | 主题 | 学完后能做什么 | 建议用时 |
| --- | --- | --- | --- |
| 阶段一 | 基础准备（Python + 数学） | 能写数据脚本、读懂公式 | 2–4 周 |
| 阶段二 | 机器学习与深度学习基础 | 能训练一个简单模型、懂神经网络 | 4–8 周 |
| 阶段三 | 大语言模型原理 | 能说清 Transformer 与大模型工作方式 | 2–4 周 |
| 阶段四 | 微调与对齐 | 能自己微调一个开源模型 | 3–6 周 |
| 阶段五 | 推理优化与部署 | 能把模型跑起来、做服务化部署 | 3–6 周 |
| 阶段六 | 应用与工程落地 | 能做出 RAG / Agent 应用 | 4–8 周 |
| 阶段七 | 持续进阶 | 能读论文、跟进前沿、独立探索 | 长期 |

整体是一条"自底向上"的路径：**不急着追新模型，先夯实地基，再用工程手段把能力用起来**。

## 1.2 阶段一：基础准备

**目标**：能熟练写 Python 处理数据，能看懂机器学习公式。

- **Python 编程**：基础语法、数据结构、面向对象、异常与调试
- **常用库**：`numpy`（数组运算）、`pandas`（表格处理）、`matplotlib`（可视化）
- **数学基础**（够用即可，不用系统啃完）：
  - 线性代数：矩阵、向量、矩阵乘法（大模型的注意力计算核心）
  - 微积分：导数、链式法则、梯度（反向传播的数学基础）
  - 概率统计：分布、期望、最大似然估计
- **工程工具**：Git 版本管理、Linux 基础命令、虚拟环境（conda/venv）

> 小技巧：基础阶段不要单独"学数学"，边写 `numpy` 边理解线性代数，遇到公式再补概念，效率更高。

## 1.3 阶段二：机器学习与深度学习基础

**目标**：理解机器学习流程，能训练并调优一个简单神经网络。

- **机器学习入门**：监督/无监督、训练集与测试集、损失函数、过拟合与正则化
- **经典算法**：线性回归、逻辑回归、决策树/随机森林（理解即可，不必精研）
- **神经网络基础**：神经元、激活函数、前向传播、反向传播、梯度下降
- **常用模型结构**：CNN（图像）、RNN/LSTM（序列，了解即可）
- **框架上手**：以 **PyTorch** 为主，学会 `Dataset`/`DataLoader`、`nn.Module`、`optimizer`、训练循环

> 动手项目：用 PyTorch 在公开数据集上训练一个图像分类模型（如 MNIST/CIFAR），完整走一遍"数据 → 建模 → 训练 → 评估"。

## 1.4 阶段三：大语言模型原理

**目标**：能讲清楚 GPT 这类大模型"凭什么会说话"。

- **Transformer 架构**：Self-Attention、多头注意力、位置编码、Feed-Forward、LayerNorm
- **Token 与分词器**：为什么文本要切成 token，tokenizer 的作用
- **预训练**：自回归语言建模（next token prediction）、训练数据与规模效应
- **上下文机制**：Attention 如何"看到"长文本、上下文窗口的意义
- **主流模型与开源生态**：GPT 系列、LLaMA、Qwen、DeepSeek 等，了解它们的关系与许可证差异

> 推荐用 Hugging Face 的 `transformers` 加载一个小模型（如 `Qwen`/`gpt2`）打印输出，直观感受"预测下一个词"。

## 1.5 阶段四：模型微调与对齐

**目标**：能把开源模型调整成符合自己任务的形态。

- **Prompt 工程**：提示词设计、few-shot、system prompt——成本最低、最先掌握
- **指令微调（SFT）**：构造指令数据集、训练目标
- **高效微调（PEFT）**：**LoRA / QLoRA** 原理与实战（只训练低秩矩阵，省显存）
- **对齐（Alignment）**：RLHF / DPO 是什么、为什么模型需要对齐
- **训练流程**：数据清洗 → 训练 → 评估 → 迭代

> 动手项目：用 LoRA 在单卡（或免费云 GPU）上把一个小模型微调成"领域问答"模型。

## 1.6 阶段五：推理优化与部署

**目标**：让模型"跑得快、占得少、能对外服务"。

- **模型量化**：GGUF、INT8/INT4，为什么量化能省显存、代价是什么
- **推理加速**：KV Cache、批处理（batching）、投机采样
- **推理框架**：vLLM、Ollama、llama.cpp 等选型对比
- **服务化部署**：把模型封装成 OpenAI 兼容 API、并发与显存管理
- **本地部署 vs 云 API**：成本、延迟、数据隐私的权衡

> 动手项目：用 vLLM 或 Ollama 本地跑一个开源模型，封装成 HTTP 接口并测并发。

## 1.7 阶段六：应用与工程落地

**目标**：做出真正能用的 AI 应用。

- **RAG 检索增强生成**：向量化 → 向量数据库 → 检索 → 拼接上下文，解决"模型不知道你的私有知识"
- **Agent 与工具调用**：Function Calling、ReAct、多步推理，让模型"能调用工具、能执行任务"
- **多模态初步**：了解视觉/语音模型如何接入
- **评估**：怎么判断应用好不好——评测集、指标（准确率/召回）、A/B 测试
- **工程化**：提示词模板管理、成本控制、缓存、可观测性

> 动手项目：做一个带私有知识库的问答机器人（RAG），再给它加"查天气/查资料"等工具调用能力。

## 1.8 阶段七：持续进阶

**目标**：具备独立跟进与探索前沿的能力。

- **论文阅读方法**：先看摘要与结论、抓关键贡献，再深入公式与实验
- **关注方向**：推理大模型（Reasoning）、多模态、长上下文、Agent 框架、高效训练
- **参与社区**：Hugging Face、GitHub 开源项目、技术博客与会议（如 NeurIPS/ICML 概览）
- **持续实践**：把学到的每个模块沉淀成笔记（本博客的每一章）、定期复盘

## 1.9 资源与建议

**常用资源**
- 框架/模型：Hugging Face `transformers`、PyTorch、vLLM、Ollama
- 中文开源模型：Qwen（通义千问）、DeepSeek、GLM（智谱）
- 课程/文档：各框架官方文档优先，公开课程（如吴恩达《机器学习》《深度学习》）、相关论文解读

**几条建议**
1. **以项目驱动**：每个阶段配一个小项目，学完就练，避免"只看不写"。
2. **先会用，再懂原理**：先在云 API/开源模型上跑通，再回来啃 Transformer 细节。
3. **量力选卡**：学习初期不必上大显存显卡，小模型 + 云 GPU 完全够。
4. **写笔记**：像本博客一样，把每次实验和踩坑记录下来，巩固认知。
